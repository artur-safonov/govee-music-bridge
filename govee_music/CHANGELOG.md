# Changelog

## 1.1.0

- First public release.
- Lamps and Home Assistant helper names are add-on options instead of constants in the source.
- Optional button integrations (group colour script, light group, toggle script, power intent) are
  switched off unless configured.
- A configuration error stops the daemon with a readable message instead of a restart loop.
- The development SSH transport requires a pinned host key; the add-on uses local BlueZ.

## 1.0.1

- Private release driving two H6076 lamps.
